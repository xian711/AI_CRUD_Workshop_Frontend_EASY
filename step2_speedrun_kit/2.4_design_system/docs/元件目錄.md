# App* 共用元件目錄

> 本目錄涵蓋原專案 `frontend/components/` 底下的共用元件（`App*` 前綴的複合元件，以及 Card / Form / View / Section / Stat 系列輔助元件）。
> 每個元件列出：**用途 / Props / Events / Slots / 使用範例 / 注意事項**。Props 型別與預設值取自各元件原始碼的 `defineProps` / `withDefaults`。
>
> ⚠️ 本 kit **未打包這些元件的 `.vue` 原始碼**（它們依賴專案 composable 如 `useAuth`、`useSidebar`、`useTableSort`）。要沿用請從原專案 `frontend/components/` 複製對應檔案，元件內部樣式皆已使用設計系統 token。
>
> 通則：所有 23 個元件**皆無 `defineExpose`**；三個 Card 元件為 `UCard` 薄包裝（零 Props，靠 `v-bind="$attrs"` 透傳）。

## 元件索引

| 類別 | 元件 |
|------|------|

## 導航 / 版面

### AppBreadcrumb

頁首麵包屑 / 標題列，含 Teleport 動作按鈕注入點（`#breadcrumb-actions`、`#breadcrumb-actions-left`）與首頁「所屬單位」下拉。

| Prop | 型別 | 預設 | 說明 |
|------|------|------|------|
| `pageTitle` | `string` | `'首頁'` | 標題模式的標題 |
| `breadcrumbs` | `BreadcrumbItem[]` | `[]` | 有值即進入麵包屑模式 |
| `background` | `string \| null` | `null` | 覆蓋麵包屑背景（如災時桃粉）；未傳則 `bg-surface` |

`BreadcrumbItem`：`{ label: string; to?: string; icon?: string }`　**Events / Slots**：無（動作按鈕改用 Teleport DOM id 注入）。

```vue
<AppBreadcrumb page-title="消防栓管理" />
```

**注意**：label / icon 必須與 sidebar `navLinks` 一致，由 layout 的 `sidebarRouteMap` 統一定義；**不要**在 `definePageMeta` 自寫群組名或 icon。頁面主要操作 Teleport 到 `#breadcrumb-actions`，按鈕統一 `size="md"`。

`TabBarItem`：`{ label: string; icon?: string; badge?: string | number; disabled?: boolean }`
**Events**：`update:modelValue (value: number)`　**Slots**：無對外具名 slot。

```vue
<AppTabBar v-model="basicActiveTab" :items="basicTabs" variant="underline" />
```

### AppSegmentedControl

雙向 / 多向切換器（首頁平時↔災時、列表檢視切換等）。

| Prop | 型別 | 預設 |
|------|------|------|
| `modelValue` | `string` | （必填） |
| `options` | `Option[]` | （必填） |
| `ariaLabel` | `string` | `'切換'` |

`Option`：`{ label: string; value: string; icon?: string; tone?: 'default' | 'disaster' | 'success' }`
**Events**：`update:modelValue (value: string)`　**Slots**：無。

```vue
<AppSegmentedControl
  :model-value="viewMode"
  :options="[
    { value: 'peacetime', label: '平時', icon: 'i-heroicons-sun' },
    { value: 'disaster',  label: '災時', icon: 'i-heroicons-exclamation-triangle', tone: 'disaster' },
  ]"
  aria-label="平時/災時切換"
  @update:model-value="viewMode = $event"
/>
```

**注意**：`tone: 'disaster'` 讓該段套災時橘，配合模組底色規則使用。

## 覆蓋層

### AppDrawer

可從上/下/左/右滑出的抽屜，行動裝置可自動改為底部上滑。

| Prop | 型別 | 預設 | 說明 |
|------|------|------|------|
| `modelValue` | `boolean` | （必填） | 開關 |
| `title` | `string` | `''` | |
| `side` | `'right' \| 'left' \| 'top' \| 'bottom'` | `'right'` | |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'page'` | `'md'` | sm 400 / md 560 / lg 720 / xl 960 px |
| `closable` | `boolean` | `true` | 顯示關閉鈕 |
| `closeOnOverlay` | `boolean` | `true` | |
| `closeOnEsc` | `boolean` | `true` | |
| `responsive` | `boolean` | `true` | <768px 時右/左抽屜自動改底部上滑 |

**Events**：`update:modelValue (boolean)`、`close ()`　**Slots**：`header`、預設（body）、`footer`。

```vue
<AppDrawer v-model="rightMd" title="基本 Drawer（md）" size="md">
  <p class="text-on-surface-variant">寬度 560px，適合一般新增/編輯表單。</p>
  <template #footer>
    <UButton color="secondary" variant="outline" @click="rightMd = false">取消</UButton>
    <UButton color="primary" variant="solid">儲存</UButton>
  </template>
</AppDrawer>
```

### AppConfirmModal

確認對話框（刪除 / 停用等 danger / warning / info 的 alertdialog）。

| Prop | 型別 | 預設 | 說明 |
|------|------|------|------|
| `modelValue` | `boolean` | （必填） | 開關 |
| `title` | `string` | （必填） | |
| `message` | `string` | `''` | |
| `variant` | `'danger' \| 'warning' \| 'info'` | `'danger'` | 影響圖示 / 色彩 |
| `confirmText` | `string` | `'確認'` | |
| `cancelText` | `string` | `'取消'` | |
| `loading` | `boolean` | `false` | |
| `confirmDisabled` | `boolean` | `false` | 必填未完成時鎖定確認鈕 |
| `closeOnOverlay` | `boolean` | `true` | |
| `closeOnEsc` | `boolean` | `true` | |
| `maxWidth` | `number \| string` | `480` | 複雜表單可提升至 560/640 |

**Events**：`update:modelValue (boolean)`、`confirm ()`、`cancel ()`　**Slots**：預設（內文，預設渲染 `message`）。

## 表格

### AppTableFooter

表格頁尾（分頁 + 每頁筆數下拉 + 「第 X 至 Y 項，共 N 筆」統計）。

> ⚠️ **本元件同時支援 canonical 與 legacy 兩套 props。新程式一律用 canonical。**

| Prop | 型別 | 預設 | 分類 |
|------|------|------|------|
| `currentPage` | `number` | — | **canonical** ✅ |
| `totalItems` | `number` | — | **canonical** ✅ |
| `pageSize` | `number` | `10` | **canonical** ✅（兩套共用）|
| `pageSizeOptions` | `number[]` | `[10,20,50,100]` | canonical |
| `page` | `number` | — | legacy（別名，勿用於新程式）|
| `total` | `number` | — | legacy（別名，勿用於新程式）|

解析：`resolvedPage = currentPage ?? page ?? 1`；`resolvedTotal = totalItems ?? total ?? 0`。
**Events**：`update:currentPage (number)`（canonical）、`update:page (number)`（legacy，兩者同時 emit）、`update:pageSize (number)`。

```vue
<!-- ✅ canonical（新程式用這套） -->
<AppTableFooter
  :total-items="filteredAccounts.length"
  :current-page="page"
  :page-size="pageSize"
  @update:current-page="page = $event"
  @update:page-size="pageSize = $event"
/>

<!-- ⚠️ legacy（舊頁面殘留，勿新用） -->
<AppTableFooter :total="items.length" :page="page" :page-size="10" @update:page="page = $event" />
```

### AppPagination

分頁導覽（上一頁 / 頁碼 / 省略號 / 下一頁）。多數頁面透過 `AppTableFooter` 間接使用。

| Prop | 型別 | 預設 | 說明 |
|------|------|------|------|
| `modelValue` | `number` | （必填） | 目前頁碼（1-based） |
| `total` | `number` | （必填） | **總頁數**（不是總筆數！） |
| `siblings` | `number` | `1` | 當前頁兩側顯示頁數 |
| `showFirstLast` | `boolean` | `true` | （props 定義，模板未直接引用）|

**Events**：`update:modelValue (number)`　**Slots**：無。

```vue
<AppPagination v-model="page" :total="totalPages" />
```

**注意**：`total` 是**頁數**不是筆數。原專案文件範本 `create-page.md` 曾示範 `:page-size` prop，但 AppPagination **無此 prop**（那是 AppTableFooter 的），勿混用。

### AppAddressPicker

台灣結構化地址選擇器（縣市 → 鄉鎮市區 → 路名 → 門牌巷弄），四欄各自 v-model。

| Prop | 型別 | 預設 | 說明 |

## 卡片

### CardOutlined / CardElevated / CardUnderlined

三個 `UCard` 薄包裝，差異只在邊框 / 陰影（`<style scoped>` 內），**皆無自訂 Props**，靠 `v-bind="$attrs"` 透傳所有屬性給內層 `UCard`、動態轉發所有 `$slots`（含 `#header`、`#footer`）。

| 元件 | 視覺 | 對應 COMP token |
|------|------|----------------|
| `CardOutlined` | 1px `outline-variant` 邊框、無陰影 | `--ui-comp-card-border-outlined` |
| `CardElevated` | 陰影浮起、無邊框 | `--ui-comp-card-shadow-elevated`（`0 8px 16px rgba(0,0,0,.10)`）|
| `CardUnderlined` | 底部 2px 品牌紅底線（mnd.gov.tw 風格） | `--ui-comp-card-border-bottom-underlined` |

```vue
<CardElevated>
  <div class="text-body-medium font-strong text-on-surface mb-xs">浮起卡片</div>
  <div class="text-body-medium text-on-surface-variant">帶陰影，適用需強調的內容區塊。</div>
</CardElevated>

<!-- 可透傳 UCard 屬性，例如取消內距 -->
<CardOutlined :padding="false"> … </CardOutlined>
```

**注意**：`CardUnderlined` 在原專案 `frontend/` 內**未找到使用範例**（僅元件定義）。

### StatCard

統計卡片（圖示 + 標籤 + 大數字 + 補充說明，整卡為可點擊按鈕），對應平時儀表板統計卡。

| Prop | 型別 | 預設 | 說明 |
|------|------|------|------|
| `label` | `string` | （必填） | |
| `value` | `number` | （必填） | 以 `toLocaleString()` 顯示 |
| `sub` | `string` | （必填） | 補充說明 |
| `icon` | `string` | （必填） | |
| `color` | `string` | （必填） | 圖示與數字顏色 |
| `to` | `string` | — | props 定義，但模板未直接引用（僅 emit click）|

**Events**：`click ()`（整卡點擊觸發）　**Slots**：無。

```vue
<StatCard label="開設中收容所" :value="12" sub="較昨日 +2" icon="i-heroicons-home-modern"
  color="var(--ui-sys-color-primary)" @click="goShelters" />
```

**注意**：`color` 目前接受任意色字串，建議傳 `var(--ui-sys-color-*)` 而非 hex。原專案 `frontend/` 內**未找到 `<StatCard>` 使用範例**（`pages/org/audit/index.vue` 出現的 `StatCard` 是該頁本地型別，與本元件無關）。

## 附錄：無頁面使用範例的元件
