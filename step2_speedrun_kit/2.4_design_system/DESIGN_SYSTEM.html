單一事實來源：tokens/*.css

一套「顏色、字級、間距都不用背」的設計系統

所有視覺數值都收斂成 Token（CSS 變數），分成三層。你寫元件時只查最上層、不碰原始色碼，改版時只改一個變數、全站同步。這頁本身就是用這套 Token 畫出來的。

三層架構：COMP → SYS → REF（只能往上引用）

由下往上引用：元件層引用語意層、語意層引用原始層。不可跨層、不可向下、不可硬編碼 hex。

COMP 層 · 元件 Token 逐元件的視覺決策，元件實作只查這層。--ui-comp-button-bg-primary-default、--ui-comp-input-border-focus
▲var() 向上引用 ✅
SYS 層 · 語意別名 把原始值賦予意義，設計決策集中在這層。--ui-sys-color-primary、--ui-sys-spacing-medium、--ui-sys-elevation-large
▲var() 向上引用 ✅
REF 層 · 原始數值 最底層的實際色碼與尺寸（Tailwind 色票、px 間距、圓角）。開發時禁止直接使用。#C8232C、--ui-ref-spacing-16 = 16px

引用鏈範例：一顆主要按鈕的背景

--ui-comp-button-bg-primary-default ──▶ 引用 SYS └─ --ui-sys-color-primary ──▶ 引用 REF └─ #C8232C (品牌紅，實際渲染色)

✅ COMP → SYS → REF 正確方向 ❌ COMP → REF 跨層（跳過 SYS） ❌ COMP → 硬編碼 #hex ❌ SYS → COMP 向下引用

常見違規對照（❌ 硬編碼 vs ✅ 用 token）

❌ 硬編碼色值 / 間距 / 字級
<div class="bg-[#C8232C]
  p-[12px] text-[14px]">…</div>
✅ 用語意別名
<div class="bg-primary
  p-sm text-label-small">…</div>
❌ 直接用 REF 原始 token（跨層）
<span class="text-[var(
  --ui-ref-color-red-500)]">…
✅ 用 SYS 語意
<span class="text-error">…</span>
❌ 次要色用彩色
<UButton color="secondary"
  class="bg-blue-500">次要</UButton>
✅ 次要 = 中性灰（neutral-300）
<UButton color="secondary">
  次要</UButton>
❌ Badge 不用膠囊 / Input 缺 label
<span class="rounded-md">狀態</span>
<UInput placeholder="姓名" />
✅ 膠囊 Badge + 獨立 label
<UBadge color="primary">狀態</UBadge>
<UFormGroup label="姓名">
  <UInput placeholder="請輸入姓名" />
</UFormGroup>
❌ 用 !important / scoped 強蓋元件
<style scoped>
:deep(.btn){background:#C8232C
  !important;}
</style>
✅ 改用 app.config.ts 綁 token
// app.config.ts
ui.button.color.primary.solid:
  'bg-[var(--ui-comp-button-bg
   -primary-default)] ...'

把規則餵給 AI 時的重點摘要

要 AI 幫忙寫這套系統的畫面時，把下面幾條貼進提示詞，命中率最高：

  • 三層 Token，只能往上引用：COMP → SYS → REF。元件實作優先用 --ui-comp-*；沒有對應 COMP 才退用 --ui-sys-*；永遠不要碰 --ui-ref-* 或硬編碼 hex/px。
  • 主色是品牌紅 #C8232C（--ui-sys-color-primary），不是藍色。舊文件寫的 sky-600 一律忽略，以 tokens/design-token.css 為單一事實來源。
  • 次要色是中性灰（neutral-300），刻意非彩色。次要按鈕不要塗成藍或綠。
  • 功能色語意固定：success=綠、warning=琥珀、error=紅、info=粉。每個都有配套 -hover / -container / -on-*。
  • 間距 / 圓角 / 字級一律用語意簡寫（p-md、rounded-lg、text-body-medium），禁止 arbitrary value（p-[16px]、text-[18px]）。
  • 元件硬規則：Button 五態齊全（default/hover/focus/active/disabled）；Input 的 label 永遠在上方；Badge 必須膠囊 rounded-full 且只讀；Card 圓角 16px / 內距 24px。
  • 不要用 !important 或 <style scoped> 覆蓋 Nuxt UI，要改樣式走 app.config.ts 綁 COMP token。
  • 無障礙：focus ring 用對應 -container 色；顏色不作為唯一資訊（狀態同時給文字/圖示）；支援字體縮放至 150% 不破版。
