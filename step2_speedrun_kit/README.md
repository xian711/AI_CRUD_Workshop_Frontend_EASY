# Step 2 — CRUD 快速完工秘笈

> 一句話公式：**範本給骨架、harness 給規矩、AI 出勞力。**
> 三者湊齊，一個全新 CRUD 模組半小時就能長出符合規範、可跑的骨架。

## 這一節的五個資料夾

| 資料夾 | 是什麼 | 學員在這裡做什麼 | 約略時間 |
|---|---|---|---|
| `2.1_play_template` | 玩一輪範本的說明 | 把現成範本當使用者操作一遍（新增／編輯／刪除／篩選／匯出），建立心智模型 | 10 分 |
| `2.2_docs` | 範本的 SRS / SDD 規格文件 | 需要時查規格，不必逐字讀 | 隨查 |
| `2.3_harness` | 前端 harness 四件（CLAUDE.md＋前端規則＋Design System 摘要＋複製說明；後端包列課後附錄） | 讀懂 AI 每次對話會遵守哪些鐵律 | 10 分 |
| `2.4_design_system` | Design System 摘要與 token | 知道顏色／間距一律走 token，不硬編碼 | 5 分 |
| `2.5_sample_app` | 可獨立跑的人員 CRUD 範例（範本正本） | 安裝啟動、對照 8 個核心檔、看懂哪些複製哪些共用 | 15 分 |

## 為什麼快

- **範本給骨架**：列表／明細／驗證／CSV／URL 同步／刪除確認，全部寫好了，複製改名即繼承。
- **harness 給規矩**：`CLAUDE.md` 是專案憲法，AI 每次對話自動讀，不會亂換套件、不會硬編碼顏色。
- **AI 出勞力**：改欄位、改型別、改文案這種重複勞動交給 AI，你只負責決策與驗收。

## 建議順序

1. 先玩一輪 → `2.1_play_template/玩一輪範本.md`
2. 認識規矩 → `2.3_harness/README.md`、`2.3_harness/CLAUDE.md`
3. 看懂範本 → `2.5_sample_app/README.md`
4. 動手複製新模組 → `2.1_play_template/使用說明-複製範本開發新模組.md`（完整版工作流程）
