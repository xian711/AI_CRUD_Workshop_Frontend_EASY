⑤ 循序圖：查詢與 URL 狀態同步（FR-T-101~105・601）

篩選變更即時過濾並重設頁碼；URL 僅寫入非預設值（debounce 300ms），卸載時清理排程防止跨頁污染（審查發現的必修項）。

%%{init: {'theme':'neutral','themeVariables':{'fontSize':'19px'},'sequence':{'actorFontSize':20,'messageFontSize':18,'noteFontSize':18,'width':240}}}%%
sequenceDiagram
  autonumber
  actor U as 承辦人員
  participant P as index.vue（列表頁）
  participant LP as useTemplateListPage
  participant M as useTemplateMembers
  participant R as vue-router（URL）

  U->>P: 進入 /template/crud?county=臺東縣&page=2
  P->>LP: 建構（defaultFilters, advancedKeys）
  LP->>R: 讀取 query 還原 filters/page/size
  LP-->>P: filters（進階條件有值 → 自動展開進階區）
  P->>M: records（響應式清單）
  P->>P: filtered → sorted（useTableSort）→ paged（computed 鏈）
  U->>P: 輸入關鍵字「王」
  P->>LP: filters.q = '王'
  LP->>LP: page 重設為 1（FR-T-104）
  Note over LP,R: debounce 300ms 後僅寫入非預設值（FR-T-601）
  LP->>R: router.replace({ q:'王', county:'臺東縣' })
  U->>P: 點「匯出 CSV」
  P->>P: exportCsv（sortedRows 全量・BOM・RFC 4180）
  Note over P,LP: 元件卸載 → onScopeDispose 清除 debounce 排程
＋路徑守衛（防止把列表 query 寫到明細頁 URL）

⑥ 循序圖：新增／編輯儲存（FR-T-301~305・BR-T-01~03）

驗證是純函式：規則資料化、與 UI 分離；錯誤顯示於欄位下方紅字並聚焦第一個錯誤欄位，不是只有 toast。

%%{init: {'theme':'neutral','themeVariables':{'fontSize':'19px'},'sequence':{'actorFontSize':20,'messageFontSize':18,'noteFontSize':18,'width':250}}}%%
sequenceDiagram
  autonumber
  actor U as 承辦人員
  participant D as [id].vue（明細頁）
  participant V as templateValidation（純函式）
  participant M as useTemplateMembers
  participant T as useToast

  U->>D: 進入 /template/crud/new?return=…
  D->>D: mode = create・空白表單（reactive 深拷貝）
  U->>D: 填寫欄位、按「儲存」（Teleport 麵包屑動作列）
  D->>D: payload = trim 正規化後的表單
  D->>V: validateFields(payload, rulesFor(payload))
  alt 有錯誤（例：電話格式不符 BR-T-03）
    V-->>D: { phone: '請輸入 09 開頭的 10 碼手機號碼', … }
    D->>D: 欄位下方紅字（TemplateFormField error）
    D->>D: 聚焦第一個錯誤欄位（data-field → .focus()）
    D->>T: 「請修正 N 個欄位」
    U->>D: 修正該欄位 → 只清除該欄位錯誤
  else 全部通過
    V-->>D: {}（空物件）
    D->>M: create(payload)
    M->>M: 產生 id（M-025）＋ updatedAt（本地時區）
    M-->>D: 新 TemplateMember（深拷貝）
    D->>T: 「已新增人員（綠色）」
    D->>D: navigateBack(return) → 列表狀態完整還原
  end

⑦ 循序圖：刪除（UC-T-05・FR-T-401~402・BR-T-04）

刪除必經二次確認且文案含姓名；當頁因刪除變空時自動退回前一頁。

%%{init: {'theme':'neutral','themeVariables':{'fontSize':'19px'},'sequence':{'actorFontSize':20,'messageFontSize':18,'noteFontSize':18,'width':250}}}%%
sequenceDiagram
  autonumber
  actor U as 承辦人員
  participant P as index.vue（列表頁）
  participant C as AppConfirmModal（danger）
  participant M as useTemplateMembers
  participant T as useToast

  U->>P: 點列上「刪除」（@click.stop 不觸發檢視）
  P->>C: 開啟確認框「確定刪除【王小明】？」
  alt 取消
    U->>C: 「取消」／Esc／點遮罩
    C-->>P: 關閉，不動資料
  else 確認
    U->>C: 「確認」
    C-->>P: confirm 事件（不自動關閉）
    P->>M: remove(id)
    M-->>P: 完成
    P->>P: 自行關閉 modal（v-model = false）
    P->>T: 「已刪除（綠色）」
    P->>P: 當頁清空 → page 退回前一頁（FR-T-402）
  end
