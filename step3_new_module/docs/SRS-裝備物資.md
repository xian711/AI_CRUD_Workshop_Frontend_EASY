# SRS — 中心裝備物資（課堂版 v1.0）

> 需求規格。範圍依課堂版 PRD（12 欄）＋三個決策點的拍板結果。
> 章節骨架沿用範本的需求規格（`step2_speedrun_kit/2.1_sample_app/SPEC-範例-人員CRUD.md`），內容精簡為工作坊參考解。

## 1. 目的與範圍

- 目的：在 CRUD 標準範本上，示範「複製改名開新模組」開發出中心裝備物資清冊管理。
- 範圍內：品項的新增／檢視／編輯／刪除、關鍵字＋分類＋狀態篩選、排序、分頁、URL 同步、CSV 匯出、品項編碼自動產生。
- 範圍外：借用歸還、維保效期提醒、照片與手冊、匯入 Excel、常用地點管理、級聯地址、同編碼累加數量、後端串接、權限。

## 2. 名詞

| 名詞 | 說明 |
|------|------|
| 品項 | 一筆裝備物資（EquipmentItem） |
| 分類 | 10 大分類（資通訊設備…其他），每類有類別碼與標準項目清單 |
| 品項編碼 | 系統依「分類＋項目」自動產生的識別碼，格式 `{類別2碼}-{項目3碼}-{流水3碼}` |

| 編號 | 功能 | 需求 |
|------|------|------|

| FR-EQ-201 | 排序 | 點表頭切換單欄升降冪，可排：分類／項目／數量／狀態／採購日期 |

## 4. 欄位規格（12 欄）

| 中文 | 欄位名 | 型別 | 必填 | 元件 | 驗證／規則 |

| 項目 | `name` | string | ✔ | 下拉（依分類連動）／文字 | 先選分類；「其他」分類改文字輸入 |
| 品項編碼 | `code` | string | 系統 | 唯讀 | 自動產生，見 BR-EQ-01 |
| 數量 | `qty` | number | ✔ | 數字 | ≥ 0 |
| 單位 | `unit` | string | ✔ | 文字 | 不可空白 |
| 規格說明 | `spec1` | string | ✔ | 多行文字 | 不可空白 |
| 保管人 | `keeper` | string | ✕ | 文字 | — |
| 保管人電話 | `keeperPhone` | string | ✕ | 文字 | 有填才驗（BR-EQ-02） |
| 存放地點 | `locationName` | string | ✕ | 文字 | — |

## 5. 業務規則（BR）

| 編號 | 規則 |
|------|------|
| BR-EQ-01 | 品項編碼 = `{類別2碼}-{項目3碼}-{流水3碼}`；類別碼查 `EQUIPMENT_CATEGORIES.code`、項目碼查 `ITEM_CODE_MAP`（查無或「其他」分類用 `OTH`）；同「類別+項目」前綴內流水 001~999 遞增。課堂簡化：允許同分類＋項目建立多筆，每筆流水號遞增、編碼仍唯一，不做同碼累加數量 |
| BR-EQ-02 | 保管人電話選填；填了才驗，接受台灣手機（09 開頭 10 碼）或市話（區碼＋7~8 碼，可含一個連字號） |
| BR-EQ-03 | 採購日期選填；填了不可晚於本地今天 |
| BR-EQ-04 | 狀態配色：正常＝綠、維修中＝黃、已報廢＝紅 |

## 6. 非功能需求（NFR）

| 編號 | 需求 |
|------|------|
| NFR-EQ-01 | 桌機與手機顯示資訊等價 |
| NFR-EQ-02 | 錯誤訊息以 `aria-describedby` 關聯輸入元件 |
| NFR-EQ-03 | 衍生資料一律 computed，template 內不做 O(n) 掃描 |
| NFR-EQ-04 | 樣式走 design token 別名，零硬編碼 hex／px；日期用原生 `UInput type="date"` |

## 7. 驗收條件

1. 進 `/equipment/crud`：桌機表格、預設每頁 20 筆、預設分類→項目升冪，正確顯示總筆數。
2. 分類選「資通訊設備」→ 只列該分類；清空分類→ 全列。
3. 關鍵字輸入 `IT-LAP` 能過濾出對應品項（不分大小寫、部分比對）。
4. 點表頭「數量」切換升／降冪，排序後回第 1 頁。
5. 新增頁選定「分類＋項目」→ 標題區即時顯示自動編碼；未填齊必填時送出顯示紅字並聚焦。
6. 新增／編輯後返回列表立即生效（同一資料源）；刪除經二次確認後移除。
7. 保管人電話填非法格式送出被擋；採購日期選未來日期送出被擋。
8. 匯出 CSV 為全量、含 BOM、Excel 開啟不亂碼。

## 8. 種子資料

24 筆虛構測試資料，涵蓋全部 10 分類、三種狀態皆出現，品名取自真實裝備清單（發電機、避難帳篷、急救箱…）。
