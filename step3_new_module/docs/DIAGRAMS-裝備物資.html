② 零件圖：哪些照範本改名、哪些直接共用

新模組用了範本的 8 個檔：5 個複製一份改名字，3 個直接拿來用、一個字都沒改。

怎麼看
  • 綠色框：照範本複製、改名（5 個）。跟「裝備長什麼樣」有關，所以要有自己的一份。

③ 資料圖：一筆裝備記哪些資料

一筆裝備記 12 項資料；分類和狀態只能從固定的選項裡選，品項編碼由系統自己組。

怎麼看
  • 左邊大框是「一筆裝備」，一行一項資料。有 ★ 的一定要填。
  • 右邊三個框是固定的東西：分類只有 10 類、狀態只有 3 種、編碼照固定規則組。
  • 箭頭上的字說明兩邊的關係。項目清單跟著分類變，太長不畫，見 PRD 第 4 節。
%%{init: {'theme':'neutral','themeVariables':{'fontSize':'22px'}}}%%
classDiagram
  direction LR
  class Item["一筆裝備（12 項資料）"] {
    ★ 分類
    ★ 項目
    品項編碼（系統自己編）
    ★ 數量（0 以上的整數，新增時是 0）
    ★ 單位
    ★ 規格說明（可寫好幾行）
    保管人
    保管人電話（手機、市話都收）
    存放地點
    ★ 狀態（新增時預設正常）
    採購日期（最晚到今天）
    備註（可寫好幾行）
  }
  class Category["分類（固定 10 類）"] {
    <<固定選項>>
    資通訊設備　IT
    供電及照明設備　PW
    儲物設備　ST
    事務用品　OF
    個人防護裝備　PP
    支援避難收容設施　SH
    自用緊急物資　EF
    醫療及衛生用品　MD
    清消及過濾設備　DC
    其他　OT（自己打品名）
  }
  class Status["狀態（固定 3 種）"] {
    <<固定選項>>
    正常　綠色
    維修中　黃色
    已報廢　紅色
  }
  class Code["品項編碼怎麼組"] {

    項目 3 碼（「其他」類一律 OTH）
    流水號 3 碼（刪掉的號碼不再發）
    改了分類或項目，就換新編碼
    例：PW-GEN-001
  }
  Item --> Category : 分類從這 10 類選
  Item --> Status : 狀態從這 3 種選
  Item ..> Code : 編碼照這個規則組

④ 流程圖：新增一筆裝備

選好分類和項目，編碼馬上出現；按儲存先檢查，沒過就停在原頁面標紅字，通過才存進清冊。

怎麼看
  • 上面四個方框是「角色」：管理人員、新增畫面、檢查規則、裝備清冊。
  • 從上往下是時間順序，圓圈裡的數字是第幾步。實線箭頭是「去做」，虛線箭頭是「回覆」。
  • 「如果」框分成上下兩半：上半是檢查沒過，下半是檢查通過，兩種只會發生一種。
%%{init: {'theme':'neutral','fontSize':22,'themeVariables':{'fontSize':'22px'},'sequence':{'actorFontSize':22,'messageFontSize':22,'noteFontSize':22,'width':200,'actorMargin':40}}}%%
sequenceDiagram
  autonumber
  actor U as 管理人員
  participant F as 新增畫面
  participant C as 檢查規則
  participant L as 裝備清冊
  U->>F: 按「新增品項」
  F-->>U: 空白表單：分類、項目「請選擇」，狀態預設正常
  U->>F: 選分類「供電及照明設備」
  F-->>U: 項目只列這一類的 5 項
  U->>F: 選項目「發電機」
  F->>L: 發電機發過的最大號是幾號？（刪掉的也算）
  L-->>F: 最大是 PW-GEN-002
  F-->>U: 馬上顯示編碼 PW-GEN-003
  U->>F: 填數量、單位、規格說明，按「儲存」
  F->>C: 必填、電話、數量、日期都對嗎？
  alt 檢查沒過
    C-->>F: 哪幾格錯、錯在哪
    F-->>U: 錯的那一格下面出現紅字
    F-->>U: 右下角提示「請修正 N 個欄位」，頁面不跳走
  else 檢查通過
    C-->>F: 全部通過
    F->>L: 存進去（存檔這一刻再算一次編碼）
    L-->>F: 存好了
    F-->>U: 回到清冊，總筆數多 1 筆
  end

⑤ 狀態圖：正常、維修中、已報廢怎麼變

新增時狀態預設「正常」（Q5）；東西壞了送修、修好了改回來、不能用了就報廢。已報廢就回不去（Q7）。

怎麼看
  • 黑色圓點是起點：新增一筆時從這裡開始。框的顏色就是清冊上狀態標籤的顏色。
  • 箭頭上的字是「平常什麼時候改」。
  • 已報廢沒有往外的箭頭：報廢了就回不去，編輯時狀態鎖住。登記錯了，刪掉重新新增（Q7）。
%%{init: {'theme':'neutral','themeVariables':{'fontSize':'22px'}}}%%
stateDiagram-v2
  direction TB
  state "正常（綠）" as Normal
  state "維修中（黃）" as Repair
  state "已報廢（紅）" as Scrap
  [*] --> Normal : 新增時預設
  Normal --> Repair : 壞了，送修
  Repair --> Normal : 修好了
  Normal --> Scrap : 不能用了
  Repair --> Scrap : 修不好
  note right of Scrap : 回不去（Q7）
  classDef ok fill:#e6f4ea,stroke:#2e7d32,stroke-width:3px
  classDef warn fill:#fff8e1,stroke:#f9a825,stroke-width:3px
  classDef bad fill:#fdecea,stroke:#c62828,stroke-width:3px
  class Normal ok
  class Repair warn
  class Scrap bad
