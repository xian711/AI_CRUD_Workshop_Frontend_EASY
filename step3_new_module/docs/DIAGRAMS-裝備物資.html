③ 資料模型類別圖：一筆品項長什麼樣

一筆品項（EquipmentItem）有 12 個業務欄位＋系統流水 id；欄位名就是未來後端 API 的介面。編碼由分類的 2 碼＋項目的 3 碼＋流水 3 碼組成。

%%{init: {'theme':'neutral','themeVariables':{'fontSize':'22px'}}}%%
classDiagram
  class EquipmentItem {
    +string id  「E-001」系統流水
    +string code  「IT-LAP-001」系統產生
    +string categoryKey  分類
    +string name  項目
    +number qty  數量，≥ 0
    +string unit  單位
    +string spec1  規格說明
    +string keeper  保管人
    +string keeperPhone  保管人電話
    +string locationName  存放地點
    +EquipmentStatus status  狀態
    +string purchaseDate  採購日期 YYYY-MM-DD
    +string specNote  備註
  }
  class EquipmentStatus {
    <<enumeration>>
    normal 正常・綠
    maintenance 維修中・黃
    scrapped 已報廢・紅
  }
  class EQUIPMENT_CATEGORIES {
    <<lookup table>>
    value 例：ICT
    code 類別 2 碼，例：IT
    label 中文，例：資通訊設備
    items 該分類的標準項目
  }
  class ITEM_CODE_MAP {
    <<lookup table>>
    項目名 → 項目 3 碼
    例：筆記型電腦 → LAP
    查無或「其他」分類 → OTH
  }
  class useEquipmentItems {
    +records: Readonly Ref~EquipmentItem[]~
    +getById(id) Promise~EquipmentItem?~ 深拷貝
    +create(input) Promise~EquipmentItem~
    +update(id, input) Promise~EquipmentItem~
    +remove(id) Promise~void~
  }
  class nextEquipmentCode {
    <<function>>
    +nextEquipmentCode(categoryKey, name) string
  }
  useEquipmentItems --> EquipmentItem : 管理多筆（module 單例）
  EquipmentItem --> EquipmentStatus : status
  EquipmentItem ..> EQUIPMENT_CATEGORIES : categoryKey 查表
  useEquipmentItems ..> nextEquipmentCode : create／update 時呼叫
  nextEquipmentCode ..> EQUIPMENT_CATEGORIES : 類別 2 碼
  nextEquipmentCode ..> ITEM_CODE_MAP : 項目 3 碼

④ 循序圖：新增品項＋編碼產生

選定分類和項目後，編碼馬上算出來給你看；按儲存先驗證，有錯就紅字並停在表單頁，全對才寫入，寫入時再算一次編碼，保證不重複。

%%{init: {'theme':'neutral','fontSize':22,'themeVariables':{'fontSize':'22px'},'sequence':{'actorFontSize':22,'messageFontSize':22,'noteFontSize':22,'width':260}}}%%
sequenceDiagram
  actor U as 管理人員
  participant D as [id].vue（明細頁）
  participant M as useEquipmentItems
  participant V as templateValidation
  participant T as useToast

  U->>D: 進入 /equipment/crud/new
  D->>D: 新增模式・空白表單（狀態預設「正常」）
  U->>D: 選分類「資通訊設備」
  D->>D: 項目下拉只列這個分類的標準項目
  U->>D: 選項目「筆記型電腦」
  D->>M: nextEquipmentCode('ICT', '筆記型電腦')
  M-->>D: IT-LAP-003（同前綴最大流水 ＋1）
  D->>D: 標題區即時顯示編碼（唯讀）
  U->>D: 填數量、單位、規格說明，按「儲存」
  D->>V: validateFields(form, rulesFor())
  V-->>D: 錯誤清單（必填、電話格式）
  D->>D: 另外檢查：數量 ≥ 0、採購日期不晚於今天
  alt 有錯誤
    D->>D: 欄位下方紅字＋聚焦第一個錯誤欄位
    D->>T: 「請修正 N 個欄位」，停在表單頁
  else 全部通過
    D->>M: create(payload)
    M->>M: 產生 id（E-025）＋再算一次 code，保證不重複
    M-->>D: 新品項（深拷貝）
    D->>T: 「已新增品項」（綠色）
    D->>D: 返回列表，總筆數 ＋1
  end
