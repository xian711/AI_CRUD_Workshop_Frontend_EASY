## 做的過程中踩到的坑（進教材）

| # | 坑 | 怎麼處理 |
|---|---|---|
| C1 | 打開舊資料時，項目被清空。原因：程式寫成「分類一變就清項目」，而載入舊資料時，分類也算「變了」 | 改成「目前的項目不屬於新分類才清」。載入的項目本來就屬於那一類，不會被清 |
| C2 | 分類照筆劃排、數量 10 排在 9 前面。原因：排序預設用文字比較 | 排序時分類改用「在分類表的第幾個」，數量改用數字大小 |
| C3 | 數量不能小於 0、採購日期不能晚於今天，共用的檢查規則做不到 | 在畫面的儲存動作裡另外檢查，再跟共用規則的結果合在一起。共用檔不改 |
| C4 | 共用的列表工具只吃文字，篩選下拉要顯示中文 | 分類、狀態篩選直接用中文名當值，「全部」當「不篩選」 |
| C5 | 「今天」用國際標準時間算，台灣早上 8 點前會差一天 | 改用電腦本地的日期 |
| C6 | 刪掉最大號後，下一筆拿回同一個號碼。原因：只看「目前還在的資料」的最大號 | 另外記住每個編碼前綴「發過的最大號」，取兩者比較大的＋1 |
| C7 | 「其他」類改品名，預覽換了新號，存檔卻還是舊號。原因：預覽和存檔用了兩條不同的判斷 | 存檔改成跟預覽同一條規則：分類和品名都沒變才保留原號 |
| C8 | 在第 2 頁換排序，還停在第 2 頁 | 排序一變就回第 1 頁，網址上的頁碼也拿掉 |
